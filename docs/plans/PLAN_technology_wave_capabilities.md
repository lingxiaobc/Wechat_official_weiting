# 任务方案：科技浪潮下的长期能力公众号文章

方案 ID：PLAN-20261029-01；当前版本：6。V1—V5已交付；V6为用户2026-10-30明确要求给最终稿再加信息图以降低阅读密度。保持既有记录结构，不迁移历史任务或套用已更新且需显式调用的新技能工作流。

## 任务事实与边界

- 表面任务：根据《长期能力培养》对话形成公众号初稿与独立首读审查。
- 用户明确要求：REQ-01 | 回答科技浪潮下如何更快适应、更好生存；REQ-02 | 主要写给普通职场人；REQ-03 | 培养重新建立价值的能力，同时积累转型余地。
- 已核实事实：F-01 | 来源对话 ID 6ac9ba06-cab4-83ea-a8ac-4362a31ac8ef 已经 read_thread 读取；用户述及同事希望改做养老工作及作者关于未来机器人的假设追问。F-02 | 用户明确认同观察、学习、实验、反馈、修正与帮助他人解决问题。F-03 | 用户明确批准 V1 A-01—A-03，先初稿供审查。
- 约束：C-01 | 不预测机器人确定替代护理；不虚构作者经历；事实需原始来源。C-02 | 审查后实质修改另行批准；不发布、不推送、不自动提交。C-03 | 写入型执行代理使用独立 Git worktree；主程序只维护计划跟踪与验收。
- V3批准要求：REQ-04 | 只扫图片也能大致理解核心价值，插入用户原图与两张新信息图。C-04 | 不改现有正文，只增加图片和必要图注；原图原样复制。所有成品位于文章目录。
- 未知项：无阻止本轮初稿的未知项；保存位置与隔离按现有项目规范执行。
- 暂定假设：ASM-01 | 约2800—3500中文字与一个贯穿示例可承载主张；通过首读与字数检查检验。
- 可用输入、工具与权限：对话材料、官方论文、网页核验、文件工具及通用子代理；用户已批准项目内初稿与审查工作。

## 关键挑战诊断

- 主要诊断：D-01 | 材料众多，能力清单与抽象开头未把读者能获得的判断写具体；两次开场延迟价值兑现，长期迁移联系不足。V2由用户指出的收益不明确及新首读的具体定位补充诊断。
- 支持链：F-01, F-02, C-01 -> D-01。
- 为何关键：结构能否把能力与适应及生存连接，决定读者理解与行动。
- 竞争性诊断：ALT-01 | 主要障碍是研究不足；当前不选，因为增加论文不能替代主线组织。
- 证伪条件：用户转而要求研究综述时重新规划。
- V3主要配图挑战：核心能力、实践步骤和转型条件分散在不同段落，跳读时难以连接；由三图分别承担培养什么、怎样培养、留下什么。

## 指导方针

- G-01 | 具体读者困惑与实用判断前置，合并两次开场；个人追问、连贯行动与迁移场景说明长期收益，最后落到一个可做小任务；准确立场优先于节奏与传播。V2按已审阅R-01—R-04细化。
- 优先级：立场准确、读者理解、证据可靠、文字节奏。
- 自主范围：既定立场内调整段落、过渡和措辞；安排2—3名代理执行及验证。
- 询问条件：改变结论、读者、经历、范围、权限或验收时停工。
- 主动不做：NG-01 | 不罗列永久安全能力或职业，不加入完整书单与五年路线，避免分散主线。
- 内容结构：开头交代痛点收益和核心答案；同事养老经历引出下一轮怎么办；四步能力（问题识别、学习迁移、证据修正、协作交付）；转型条件（成果、信誉、关系、资源）；真实问题训练与个人感想。重复报表示例必须标为举例。
- V3图形方针：原图作理念总纲，新图作训练流程与适应准备；新图16:9二维、暖象牙白和低饱和青绿珊瑚色，主节点在360像素宽预览可辨；不逐节堆图、不缩小正文整段入图。

## 链式弱环节与风险

- W-01 | 将模型建议误写为作者立场 | 影响：歪曲作者；当前用户已确认核心立场，仍须核对正文。
- 进入闸门：A-02仅在A-01素材边界明确后开始；A-03仅在初稿完成后开始。
- 串行步骤：A-01 -> A-02 -> A-03。
- 可并行步骤：A-03两名审查者独立并行，均仅接收正文与标题。
- V2进入闸门：A-04仅按已批准R-01—R-04执行；A-05仅在优化稿冻结后，两名新读者只接收标题正文；不得复用读过旧稿者。所有原文件保留，仅新增优化稿及说明、复核记录。
- 中止条件：需要虚构个人经历、关键来源不支持或必须改变立场。
- V3弱环：图片中文、流程与移动端大小；每新图最多2次生成，仍有关键错则停止插入并上报。独立验证未通过须执行者按既定要求修正，不扩展正文。
- 恢复或返工：回查输入与G-01，涉及实质变化先重批；读者发现问题只提交优化建议。

## 假设与失败信号

- H-01 | 假设：追问与连贯行动比能力清单更易理解。
  - 预期观察：读者能复述能力如何帮助适应变化，并找到一个可做任务。
  - 最小验证：两名无前文上下文的读者仅读标题正文。
  - 通过标准：两人均能复述主张、指出行动且不误读为就业保证；若不通过，交付初稿及明确风险与待批修改方案，不冒称质量通过。
  - 失败信号：只记得持续学习，或理解为失业归咎个人。
  - 失败后重查：G-01、A-02案例与桥接；未经批准不改稿。
- H-02 | 假设：具体用途与可用判断前置、取消二次开场，会使读者更早感知收益。
  - 预期观察：两名新读者只读前三段可说出至少一项具体用途和继续读的理由；能定位首次兑现而非仅复述能力目录。
  - 最小验证：A-05新读者独立模拟手机与小白首读。
  - 通过标准：分别记录是否通过；主线和事实边界无误；不足时如实交付残余风险，不冒称完全解决。
  - 失败信号：只能说“学习四种能力”，仍等正文开始或误读保证就业。
  - 失败后重查：G-01、A-04的价值承诺与铺垫；只报告新建议，不擅改第二轮。
