我最近意识到了自己性格上的问题，我确实是那种不主动接近客户，缺少一定自主性的人。就比如如果有学管找到我说让我给学生规划一下或者花点时间额外补课一下，我才会去执行。但是你让我自己想到并且自己执行那基本上是很困难的时间。

当然，会有一种情况除外，那就是如果学生，家长或者客户对我很认可，比如认可我行为，方法。那么即使我亏本，耗时我也会主动地去给予帮助，给予资源，甚至做一些原先让我觉得踏出舒适圈的事情。

就比如，去年有一个小组的学生，他们物理成绩不是很好。然后当时我就决定，每次上完课留出 30 分钟，让他们留下来做卷子。我负责统计时间，看他们的正确率，以及看他们在有限时间下的表现状况。

这是因为当时我觉得我对这两位学生的感情比较深。同时他们其实也跟了我好久，我也带了很久了。所以我就更愿意去花时间和精力，不管是为他们服务也好，还是为他们解决问题。

因此我不是那种自己触达对方的那种人，相反，我是那种跟你久了之后，跟你有感情了之后，我才会付出的更多。我现在其实挺想稍微改变一下自己的性格，稍微让自己更愿意与其他人接触。

之前老板在晚上培训新员工的时候，我当时听到了一点，听到了他的一些行为，比如说他会主动询问家长学生的学习情况啊，甚至会询问家长他的一些日常啊，会去主动关心家长啊，主动关心家长的孩子啊。这些行为在我看来，我是很难很难去做到的。因为从我的性格来讲，这对我来说就非常大的考验。但是换一个角度，如果我是那位家长的话，我肯定也会被老板的这种行为给感动到。或者就是因为他对我的信任，对我的关心，我可能才会去了解他，更加的去了解他的产品。

所以我在想，如果以后我真的要去走独立开发者这条路，要去走宣传自己的产品、宣传自己的能力这条路，我是不是也要像老板这样？

今天下午的时候，同事在帮公司开发应用时，我发现他并不知道 Git 的用处，也没有使用 Git，他所有的修改都没有提交。然后他也不知道怎么利用 GitHub 或者 Git 进行多人协作。这其中让我意识到，并不是所有人都知道 Git 和 GitHub。也并不是所有人都知道怎么去使用它，熟练的使用它。

这更让我意识到，我一定要把自己的能力展示出去。我觉得重要的是能够，愿意展示自己的能力，认知。同时也愿意接受他们的批评指点。我觉得这就是后续我要做的。我要做的就是愿意展示自己的能力，展示自己的认知，同时也乐意听取他们的意见。愿意主动触达用户，了解他们的需求。

我发现我现在对展示自己的能力和认知已经没有那么抗拒了。但是我对主动触达用户，还是没能迈出那一步。可能后续要练的就是这些能力。

今天晚上我终于勇敢的跳出了那一步。我感觉我现在身体非常的急躁、焦躁。我把我那个物理题库搭载在服务器，做成网页。应用，并且在朋友圈分享出去了。

同时我还私聊了几个同僚，让他们体验并给出反馈。这对我来说是非常困难的一步。我现在只感觉自己浑身颤抖，颤抖的有点控制不住，然后全身非常的热。

这种感觉，我觉得更多的是激动吧，更多的是我终于踏出那一步了，我终于去面对我最不想面对的事情，并且为之付出，为之实践。

然后我的一个两年后端经验的同事指出了我应用中存在的极其大的问题，这让我意识到AI 确实能够给你一个看得过去的应用，但是好不好用、能不能用、是否满足需求，这个是真的需要靠经历、经验去磨、去学习、去成长的。

如果没有那位同事的提点和提醒，我可能都不会往这方面去想。可能我很长一段时间内，我的网页应用都不会往这方面去优化。估计也只有等到真正上线，大量用户真实使用，真正有问题，真正收到反馈，真正抱怨的时候，我才可能会往这方面去想。

其实我特别享受有人能够给我指点，给我提示，哪怕是批评，我觉得我也挺乐意接受的。只要是对我的成长有帮助，对我的思维能力啊，还有其他能力啊有所帮助的，我都愿意去做。

今天主动向同事发起沟通之后，我觉得我对这个的抗拒有那么一丢丢一丢丢的减轻了，这可能也是一个非常好的信号吧。
